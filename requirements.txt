# =============================================================================
#  Kairos StarVector - runtime requirements
#  Target: Python 3.13.12 on Windows x64
# =============================================================================
#  Every version is pinned with == deliberately. Loose pins were the reason
#  the previous build stopped working: yfinance changed its return shape to
#  MultiIndex columns, LightGBM removed the `verbose` argument from fit(),
#  transformers dropped `return_all_scores`, and Streamlit renamed
#  use_container_width. None of that was visible in a requirements file that
#  just said "yfinance".
#
#  Both the direct dependencies and the transitive packages that actually
#  affect stability are pinned. Every version below has been verified to
#  publish a CPython 3.13 Windows x64 wheel, so `pip install` needs no
#  compiler.
#
#  The machine-learning extras (PyTorch, transformers, LightGBM) are NOT
#  here on purpose. They add well over a gigabyte and are needed only for
#  the optional Forecast models tab. See requirements-ml.txt.
#
#  To verify nothing is being built from source:
#      pip install --only-binary :all: -r requirements.txt
# =============================================================================
