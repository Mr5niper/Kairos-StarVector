#  Only needed for the "Forecast models" tab and scripts/run_benchmark.py.
#  The chart, the alignment wave, the statistics and the cycle analysis all
#  run without any of this installed.
#
#  Install AFTER requirements.txt:
#      pip install -r requirements.txt
#      pip install -r requirements-ml.txt
#
#  Size warning, because it is easy to be caught out by it: the default PyPI
#  torch wheel for Windows bundles the CUDA runtime and comes to roughly
#  2.5 GB installed. With no NVIDIA GPU there is no reason to carry it.
#  Install the CPU-only wheel first (about 250 MB) and pip will then treat
#  the torch requirement below as already satisfied:
#
#      pip install torch==2.13.0 --index-url https://download.pytorch.org/whl/cpu
#      pip install -r requirements-ml.txt
#
#  A NOTE ON PINNING, which differs from requirements.txt on purpose.
#  Only the direct dependencies are pinned here. Their transitive
#  dependencies are left to pip, because this corner of the tree carries
#  tight internal caps that shift with every release: transformers 5.15
#  requires tokenizers<=0.23.0, and the only published build in that family
#  is now 0.23.1. Pinning a transitive package inside a moving constraint
#  like that does not freeze the install, it breaks it outright with an
#  unresolvable conflict. requirements.txt pins deeply because that tree is
#  stable and it is what goes into the executable; this one does not.
# =============================================================================
